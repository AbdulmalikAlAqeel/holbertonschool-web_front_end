# Advanced CSS - Project Overview

Welcome to the **CSS Advanced** project! This repository contains a series of tasks designed to build a modern, responsive, and visually polished website for **Techium** using advanced CSS features, modular architecture, and W3C-compliant HTML5.

---

## 📌 Project Tasks Overview

### Task 0: Base HTML & Image Assets
* Established the foundational `index.html` file using structured HTML5 markup.
* Downloaded and organized all required media assets and high-resolution images in the `images/` directory.

### Task 1: Smooth Scrolling (Effortless Transitions)
* Created the primary stylesheet structure inside `styles/1-style.css`.
* Applied smooth scrolling behavior across the entire document using `scroll-behavior: smooth` on the `html` selector.

---

## 🛠️ Technical Standards & Requirements

* **W3C Validation:** HTML files pass W3C standards without errors or warnings.
* **Browsers:** Optimized for modern Chrome versions (Chrome 78+).
* **Code Format:** Standard CSS/HTML layout, with all files ending in a newline.
* **Structure:** Clean separation of concerns with HTML structure at the root and stylesheets stored in `styles/`.
